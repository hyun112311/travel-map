# 🌍 My Travel Log & Trip Planner (세계 여행 지도 & 일정 동선 플래너)

세계 지도 위에 **여행 코스(Trip)**를 생성하고, **일자별(Day 1, Day 2...)로 세부 장소(스팟: 숙소, 맛집, 관광지, 쇼핑 등)를 묶어서 이동 동선(선)**과 일정을 한눈에 기록/계획할 수 있는 인터랙티브 웹 애플리케이션입니다.

---

## ✨ 핵심 기능

### 1. 🎒 여행 코스(Trip) 단위 일정 & 동선 플래너 (신규 추가!)
- **여행 단위 프로젝트 생성**: 예) `2박 3일 서울 감성 투어`, `3박 4일 도쿄 미식 탐방`
  - 여행 구분: 다녀온 여행(실제 기록) vs 갈 예정인 여행(코스 기획)
  - 기간(시작일~종료일), 총 예산/지출, 대표 사진, 여행 총평
- **일자별(Day 1, Day 2...) 세부 장소(스팟) 관리**:
  - `Day 탭`으로 일차별 관리 및 원클릭 `[+ Day 추가]`
  - **스팟 카테고리 5종 + 직접 추가**:
    - 🏛️ 관광/명소, 🏨 숙소/호텔, 🍽️ 맛집/카페, 🛍️ 쇼핑/액티비티, ✈️ 교통/이동, ➕ 직접입력(커스텀)
  - 세부 정보: 방문 시간대, 소요 비용(가계부), 메모/꿀팁/예약번호, 사진
- **지도 위 번호 마커 & 이동 동선(Polyline) 시각화**:
  - `D1-1 🏨`, `D1-2 🏛️`, `D1-3 🍽️` 와 같이 **일차-순서 번호 + 카테고리 아이콘**이 표시되는 스마트 핀
  - 일자별 고유 색상 점선으로 스팟 사이를 연결하여 **이동 루트를 지도 위에 선명하게 표시**
  - 사이드바에서 `Day 1`을 누르면 Day 1 동선만 집중 표시, `전체 일정`을 누르면 전 일정의 동선이 컬러별로 모두 표시
- **순서 위/아래 즉시 변경 (Reordering)**:
  - 타임라인에서 `▲` / `▼` 버튼을 눌러 스팟 방문 순서를 쉽게 바꾸면 지도 위 번호와 동선 선이 실시간으로 재계산

### 2. 📍 단일 관심 장소 핀 모드 병행 지원
- 큰 여행 코스뿐만 아니라, 기존의 가벼운 단일 관심 장소(버킷리스트 스팟 1개)도 상단 `[관심 장소]` 탭을 통해 언제든 등록 및 확인 가능합니다.

### 3. 🌐 최신 구글 지도 (Google Maps) 완벽 탑재
- API 키 없이도 전 세계 **한글 지명**과 최신 도로/건물이 지원되는 구글 지도 기본 탑재.
- **4가지 테마 원클릭 전환**:
  - 🌐 구글 표준 지도 (Google Maps)
  - 🛰️ 구글 위성 하이브리드 (위성 실사 + 도로/지명 라벨)
  - ⛰️ 구글 지형도 (Google Terrain)
  - 🗺️ Esri 세계 거리 지도

### 4. 💾 자동 이미지 압축 & 백업/복원
- **자동 이미지 압축 (Canvas)**: 스마트폰 고화질 원본 사진(5MB~15MB)도 업로드 즉시 웹 최적화(약 100KB 안팎)로 자동 압축되어 브라우저 용량 걱정 없이 가볍게 저장됩니다.
- **LocalStorage 자동 보존**: 브라우저 창을 닫아도 내 여행 데이터가 안전하게 유지됩니다.
- **JSON 백업/복원**: `[내보내기]`로 전체 여행 코스와 장소를 파일 하나로 저장하고, 다른 PC로 손쉽게 이전할 수 있습니다.
- **샘플 데이터**: 상단 `[예시 불러오기]`를 누르면 완성도 높은 2박 3일 서울 투어와 도쿄 여행 코스를 바로 확인해볼 수 있습니다.

## 📱 스마트폰(모바일)에서 확인 및 사용하는 방법

스마트폰 전용 모바일 최적화 레이아웃(하단 내비게이션 바, 터치 최적화 바텀 시트)이 완벽히 적용되어 있습니다.

### 스마트폰으로 접속하는 가장 쉬운 방법:
1. 컴퓨터와 스마트폰을 **같은 Wi-Fi(공유기)**에 연결합니다.
2. `travel-map` 폴더 안의 **`run-mobile.bat`** 파일을 더블 클릭하여 실행합니다.
3. 검은 콘솔 창에 표시되는 스마트폰 접속 주소(예: `http://192.168.0.x:8080` 또는 `http://10.14.15.147:8080`)를 스마트폰의 **사파리(Safari)**나 **크롬(Chrome)** 주소창에 입력합니다.
4. **💡 앱처럼 쓰는 꿀팁**:
   - 아이폰: 사파리 하단 공유 버튼 ➔ **'홈 화면에 추가'**
   - 안드로이드: 크롬 우측 상단 메뉴 ➔ **'홈 화면에 추가'** 또는 **'앱 설치'**
   - 이제 스마트폰 바탕화면에서 진짜 네이티브 앱처럼 풀스크린으로 실행됩니다!
